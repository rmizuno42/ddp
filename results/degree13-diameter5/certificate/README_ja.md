# 88,452頂点・13正則・直径5のグラフ

## 結果

**定理（明示的な有限構成・計算機援用証明）** 88,452頂点を持つ、単純無向13正則グラフで、直径がちょうど5であるものが存在する。

[Comellasのdegree–diameter表](https://web.mat.upc.edu/francesc.comellas/delta-d/table_degree_diameter.html)の (13,5) 欄は、2026年10月9日の確認時点で51,417である。本構成はこれを37,035頂点、**約72.028706%**上回る。依頼の「50%程度以上の改善」を満たす構成である。表への提出・掲載はまだ行っていない。

| 項目 | 検証結果 |
|---|---:|
| 頂点数 | 88,452 |
| 辺数 | 574,938 |
| 各頂点の次数 | 13 |
| 直径 | 5 |
| 距離5を超える順序付き頂点対 | 0 |
| 独立な全始点BFSの始点数 | 88,452 |

## 構成の定義

頂点は `(u,x)`、ただし `0 ≤ u < 364`、`x ∈ F₃⁵` とする。座標を `x=(x₀,y₀,x₁,y₁,z)` と書き、整数ラベルを

`243u + x₀ + 3y₀ + 9x₁ + 27y₁ + 81z`

で定める。

1. 各コントローラ頂点の4つのポートについて、同梱の行列・ベクトルを使い、`(u,x)` と `(v, A x + ℓ b)` を結ぶ。`ℓ` は F₃ の3元を走る。ループと重複を除く。
2. `data/main_matching.txt` が指定する、固定点のない対合 `m` の辺 `{v,m(v)}` を加える。
3. 残る756個の次数12の頂点を、`data/spare_matching.txt` の378辺でマッチングする。

最初の段階では、87,696頂点が次数12、756頂点が次数11となる。主マッチングはすべて新しい辺であり、全頂点の次数を1増やす。最後のマッチングが残る756頂点の次数を13にする。すべての条件を再生成プログラムが直接検査する。

詳しい行列のファイル形式、数式による定義と証明は `CONSTRUCTION.md` にある。構成を再現するために探索用SATソルバーや中間データは必要ない。

## 直径の証明

生成した明示的な辺リストを、構成プログラムとは別の検証プログラムに読み込ませ、**全88,452頂点を始点とする深さ5の幅優先探索**を行った。全始点で全頂点に到達した。対称性に基づく削減は、この検証では使用していない。

別実装では、位数7の自由な自己同型を全辺について確認した上で、12,636個の軌道代表を始点とするBFSでも同じ結果を得た。さらに、378本の補助辺のうち77本だけを加えた全域部分グラフでも、全88,452始点の検証が成功している。

最大次数13・直径4のMoore上界は

`1 + 13(1 + 12 + 12² + 12³) = 24,506`

であり、88,452はこれを超える。したがって直径は5以下であるだけでなく、**ちょうど5**である。

## 探索を突破した方法

次数を保つため、追加接続をマッチングとして扱った。有限体上の9点のアフィン平面ごとに、対応先を自由に置換する。これにより、次数とマッチング条件を保ちつつ、平行移動だけでは実現できない接続を許す。

固定したグラフにマッチングを加えたとき、長さ5以下の最短路に現れるマッチング辺は高々3本である。この事実から、各頂点対が距離5以内になる条件を、置換の割当て条件の厳密な論理式に変換できる。未達の頂点対の条件を順次追加し、候補を全頂点対の条件で検証することで、巨大な全条件を一度に扱う必要を減らした。

最後は、主マッチングの未達数を増減させない小さな置換と、補助マッチングの再最適化を組み合わせて残る穴を解消した。主接続の最後の変更は、コントローラ15のファイバー内の状態236と241を交換し、それを7個のコントローラ位相に適用する操作である。

この一般的な条件化の議論と、今回の具体的な有限グラフの証明は `CONSTRUCTION.md` に記載している。一般の次数に対する無限族は、今回の結果には含めていない。

## 再現手順

Python 3とC++17コンパイラだけで実行できる。Pythonの追加パッケージやOpenMPは不要。ZIPを展開したディレクトリで実行する。

```sh
python3 verify_checksums.py
python3 generate_graph.py
c++ -O3 -std=c++17 -pthread verify_graph.cpp -o verify_graph
./verify_graph graph.edges 2
python3 verify_checksums.py --graph graph.edges
```

最後の `2` は使用するスレッド数。`1` でも同じ検査を行う。

成功時の最終行は次のとおり。

```text
PASS: simple undirected 13-regular graph; order 88452; diameter exactly 5.
```

`graph.edges.gz` には、再生成結果と同一の辺リストも同梱した。展開後の形式は、先頭行が `88452 574938`、以後の各行が `u v`、頂点ラベルは0始まり、常に `u < v` である。

別の構成・検証実装は `independent/construct_verify.cpp` にある。実行方法は `CONSTRUCTION.md` を参照。
